## 🌐 Official Web Application
👉 **Launch the Suite in Your Browser:** **[https://multipdfdoc.com](https://multipdfdoc.com)**

**MultiPDF Doc** is an open-source, privacy-first web document application. Unlike conventional cloud PDF converters that require users to upload confidential legal, financial, or medical files to remote servers, **MultiPDF Doc executes all core operations 100% locally inside the user's browser** via modern WebAssembly (WASM) and HTML5 Canvas engines.

Your files never leave your device, no network bandwidth is wasted on server uploads, and your private documents cannot be cached, intercepted, or leaked.

## 💻 Tech Stack & WebAssembly Engines

* **Framework:** Next.js 15.5.27 (Static Export pre-rendered to HTML/JS/CSS).
* **UI & Styling:** React 19, TypeScript, Vanilla Tailwind CSS with Soft Claymorphism tokens.
* **Cryptographic Engine:** `pdfstudio` (QPDF WebAssembly v12) for AES-256 encryption and structural optimization.
* **Rendering Engine:** Mozilla `pdfjs-dist` (v4.10.38) with self-hosted Web Workers, standard fonts, and CMap assets.
* **Local OCR:** `tesseract.js` (v7.0.0) with WebAssembly LSTM neural network models running locally in dedicated Web Workers.
* **PDF Assembly:** `pdf-lib` (v1.17.1) for client-side stream concatenation and page manipulation.
* **Archive Packaging:** `jszip` (v3.10.2) for multi-file bundle creation.

## 🛠️ Local Development & Testing

### Prerequisites
* Node.js v20+ or v22 LTS
* npm v10+

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/HaarisSaifi/multipdfdoc.git
cd multipdfdoc
npm ci
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Verify Production Build & Core Invariants
```bash
# Run unit tests and real QPDF WebAssembly cryptographic invariants
npm test

# Build static production bundle
npm run build

# Preview static export
npm start
```
